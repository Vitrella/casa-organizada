## Critério de priorização
- **Alta**: alta intenção de compra + categoria com muitos produtos elegíveis na Amazon + baixa exigência de conhecimento técnico pra escrever com precisão.
- Comece pelos 8 primeiros "Alta" — eles formam o núcleo do site e já cobrem os cômodos mais buscados (cozinha, closet, garagem, banheiro).
- Artigos "how-to" (ex: #11) servem para trazer tráfego de topo de funil e linkar internamente para os roundups de compra — bom para SEO, mas não são prioridade de monetização direta.

## Regra de conteúdo (igual ao playbook do SEO dental)
Nunca inventar preço, nota de avaliação, nome de produto específico ou estatística de vendas. Cada artigo é publicado com placeholders `[PRODUTO X / ASIN / PREÇO]` que só são preenchidos com dado real (via Amazon, pesquisa manual ou API de afiliados) antes de publicar. Isso evita conteúdo enganoso e problema com o Amazon Associates (que audita a precisão do conteúdo).
